Global Variables

💡 Info: Variables can be used in queries with ${{NAME}}
Example: filter region == "${{REGION}}"

Automatic variables available:
• ${{TIMEFRAME_START}} - Timeframe start timestamp (ISO 8601: 2025-11-20T14:36:00.000Z)
• ${{TIMEFRAME_END}} - Timeframe end timestamp (ISO 8601: 2025-11-20T14:36:00.000Z)
Example: filter timestamp >= toTimestamp("${{TIMEFRAME_START}}") and timestamp <= toTimestamp("${{TIMEFRAME_END}}")
